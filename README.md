# NorthPoint Intelligence

Find. Analyze. Win.

NorthPoint Intelligence is a premium React, TypeScript, Tailwind, and Framer
Motion product experience for government contracting intelligence. It presents a
light-mode-only workspace with animated opportunity intelligence, capture
pipeline visualization, subcontractor relationship cards, proposal operations,
market intelligence, compliance, document vault, and command-center workflows.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```
